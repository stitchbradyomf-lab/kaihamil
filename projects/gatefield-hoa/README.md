# Gatefield Homeowners Association Website

**Live Site:** [gatefield-hoa.netlify.app](https://gatefield-hoa.netlify.app)

---

## About This Project

This website serves the Gatefield Homeowners Association community. It was developed with support from Kyle Brady using modern, sustainable web practices.

### Development Approach

This site demonstrates how community organizations can leverage:
- **Transparent infrastructure** - All changes tracked via GitHub
- **Low-cost hosting** - Netlify free tier with upgrade path
- **Easy content updates** - Simple markdown-based content management
- **Community ownership** - HOA maintains full control of content and domain

### Technical Stack

- **Framework:** Static site generator (11ty/Astro)
- **Hosting:** Netlify
- **Content:** Markdown files in `/content`
- **Styling:** Tailwind CSS
- **Domain:** Managed by Gatefield HOA

## For Board Members: Updating Content

### Option 1: Direct GitHub Edit (Simple Changes)
1. Go to [github.com/gatefield-hoa/website](https://github.com/gatefield-hoa/website)
2. Navigate to `/content` folder
3. Click the file you want to edit
4. Click the pencil icon (Edit)
5. Make your changes
6. Scroll down, add a description like "Update meeting date"
7. Click "Commit changes"
8. Site updates automatically in 2-3 minutes

### Option 2: Email Updates
Send content changes to: webmaster@gatefield-hoa.org

Include:
- Page/section to update
- New content (text, images, documents)
- Any special formatting needs

Turnaround: 24-48 hours

### Option 3: Advanced: OpenClaw Agent (Experimental)
For board members with Telegram:
1. Message the Gatefield bot: `@GatefieldHOABot`
2. Example: "Update the next meeting to June 15th at 7pm"
3. Bot previews change, you confirm
4. Change committed to GitHub, site updates

*Note: This requires setup and training. Contact Kyle if interested.*
