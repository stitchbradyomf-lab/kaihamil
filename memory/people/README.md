# People — Relationship Knowledge Graph

Living map of Kyle's family, friends, and associates.

## Structure

- **`graph.md`** — The full knowledge graph (Mermaid + structured notes)
- **`family.md`** — Family tree and relationships
- **`friends.md`** — Close friends and chosen family
- **`associates.md`** — Professional, neighborhood, broader network
- **`stories.md`** — Notable relationship moments worth remembering

## How To Use

When Kyle mentions someone:
1. Check if they exist in the graph
2. If new: add to appropriate file with context (relationship, how they connect, key facts)
3. If existing: update with new context
4. Update `graph.md` if it changes the structure

## Conventions

- **Person ID:** `firstname-lastname` or `firstname-relationship` (e.g., `brady-nephew` vs `brady-son`)
- **Edge types:** `parent`, `sibling`, `spouse`, `child`, `cousin`, `uncle`, `aunt`, `friend`, `colleague`, `neighbor`, `mentor`
- **Notes per person:** Age (approximate), role in Kyle's life, last seen, recent context

## Privacy

This is local-only. Never share full names, addresses, or personal details externally.
Kyle's immediate family (Marissa, Hudson, daughters) and extended family are private context.
