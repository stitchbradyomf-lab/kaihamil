# Kai Hamil Weekly Digest System

**Purpose:** Automated, transparent summary of work completed and work outstanding across all Kai Hamil systems.

**Output:** Weekly digest suitable for Life & Times integration and public/private sharing.

---

## Core Philosophy

- **Transparent:** Links to source material, not summaries of summaries
- **Incremental:** Captures work as it happens, not just at week-end
- **Multi-source:** Pulls from OpenClaw, PocketBase, GitHub
- **Actionable:** Outstanding items clearly surfaced
- **Attributable:** Who did what, when

---

## Data Sources

### 1. OpenClaw (Internal Operations)

**What to capture:**
- Agent tasks completed (Gavin research, Connie drafts, etc.)
- Cron job executions and outputs
- File operations (created, modified, deleted)
- User interactions (commands, requests)

**Data location:**
- `~/.openclaw/cron/jobs.json` — scheduled task status
- `~/.openclaw/sessions/` — session logs
- `~/.openclaw/workspace/` — file changes

**Schema:**
```json
{
  "source": "openclaw",
  "type": "task_completed|file_modified|cron_executed",
  "timestamp": "2026-05-11T12:00:00Z",
  "agent": "stitch|gavin|connie|...",
  "description": "Brief description",
  "link": "path/to/artifact",
  "status": "completed|failed|pending"
}
```

### 2. PocketBase (Runtime Data)

**What to capture:**
- Time & Focus entries (daily ratings)
- Business tracker entries (when live)
- Brief configs and topics
- User data changes

**Data location:**
- `time_focus_entries` collection
- `brief_configs`, `brief_topics`, `brief_items`
- Custom collections (future)

**Schema:**
```json
{
  "source": "pocketbase",
  "collection": "time_focus_entries|brief_configs|...",
  "type": "created|updated|deleted",
  "timestamp": "2026-05-11T12:00:00Z",
  "record_id": "...",
  "summary": "Human-readable summary",
  "link": "https://pb.kaihamil.com/_/#/collections/..."
}
```

### 3. GitHub (Code & Content)

**What to capture:**
- Commits to kaihamil repo
- Pull requests (opened, merged, closed)
- Issues (created, closed, updated)
- Content published (research, drafts, specs)

**Data location:**
- `stitchbradyomf-lab/kaihamil` repository
- Commit history
- Issue tracker

**Schema:**
```json
{
  "source": "github",
  "type": "commit|pr|issue|release",
  "timestamp": "2026-05-11T12:00:00Z",
  "author": "stitchbradyomf",
  "title": "Commit/PR/Issue title",
  "description": "Body or summary",
  "link": "https://github.com/stitchbradyomf-lab/kaihamil/commit/...",
  "files_changed": ["path/to/file"],
  "status": "completed|open|merged"
}
```

## Design Decisions (Resolved)

| Question | Decision |
|----------|----------|
| **Privacy** | Private — directed to Kyle only |
| **Scope** | Personal + Business — all data Stitch/agents can access |
| **Review** | Fully automated — no human check before publishing |
| **Attribution** | Credit both human and agent work transparently |
| **Granularity** | Weekly primary digest, optional daily incremental |
| **Location** | `operations/digest/` in kaihamil repo |
