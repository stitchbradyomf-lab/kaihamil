# Chick-fil-A Systems Analysis — 60 Second Script

## Hook (0-5s)
"Chick-fil-A does $9 million per location with 2,800 stores. Here's the system behind it."

## Component 1: Extreme Selection (5-15s)
"First, they reject 99% of franchise applicants. They invest $100,000 training each operator. They're not buying real estate — they're buying human capital quality."

## Component 2: Single-Unit Focus (15-25s)
"Second, one operator, one store. No absentee owners. 40 to 50 hours a week hands-on. This is deep operational involvement, not portfolio management."

## Component 3: Asset Ownership (25-35s)
"Third, corporate owns everything — real estate, equipment, the building. This lets them enforce standards instantly. No negotiating with independent owners."

## Component 4: Profit-Sharing (35-45s)
"Fourth, profit-split, not just royalties. About 50-50. The operator wins when the store wins. True partnership, not extraction."

## Component 5: Cultural Replication (45-55s)
"These four inputs feed a cultural engine — 'My Pleasure,' servant leadership, values that actually permeate. The result is consistency across every location."

## Close (55-60s)
"Operational excellence isn't an accident. It's a system with five levers. What system should I break down next?"

---

## Visual Cues for Recording

- **0-5s:** Full diagram visible, point to outcome box
- **5-15s:** Point to "Extreme Selection" box (top left)
- **15-25s:** Point to "Single-Unit Focus" box (top middle-left)
- **25-35s:** Point to "Asset Ownership" box (top middle-right)
- **35-45s:** Point to "Profit-Sharing" box (top right)
- **45-55s:** Point to "Cultural Replication" box (center)
- **55-60s:** Pull back to full diagram, gesture to all five components

## Key Numbers to Remember
- <1% acceptance rate
- $100K+ training per operator
- $9M+ average unit volume
- 2,800+ locations
- ~50/50 profit split
- 40-50 hrs/week operator commitment
