# Kai Hamil Operations Digest

**Private weekly summary of all Kai Hamil activity.**

## Purpose

This directory contains automated weekly digests tracking:
- Work completed (content, tools, operations)
- Tasks outstanding (prioritized)
- Trends and insights
- Personal and business metrics

## Audience

**Kyle only.** These digests are private, fully automated, and include all data accessible to Stitch/agents (OpenClaw, PocketBase, GitHub).

## Format

Each digest is a dated markdown file:
- `YYYY-MM-DD-weekly.md` — Weekly digest
- `index.json` — Metadata for all digests
- `trends.json` — Aggregated metrics over time

## Schedule

- **Generated:** Sundays at 6:00 PM ET
- **Posted to:** This directory + Telegram summary
- **Retention:** All digests kept indefinitely

## Contents

- At-a-glance metrics
- Completed work (categorized)
- Outstanding tasks (prioritized)
- Trends & insights
- Source links
